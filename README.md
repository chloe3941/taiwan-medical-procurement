# 臺灣醫院醫療器材採購資訊追蹤與歷史資料庫

公開網站部署完成後，網址預計為 https://chloe3941.github.io/taiwan-medical-procurement/

## 網站功能
- 醫院醫材採購案件查詢與篩選
- 部立醫院、公立醫院及醫學中心採購資訊彙整
- 近三年部立醫院聯合採購投標／決標歷史資料（逐案核實後匯入）
- 顯示公告日期、機關、標案名稱及案號、預算、招標方式、截止時間、狀態及官方來源
- 區分「已核實」與「待確認」

## 資料維護
主要資料檔：`data/tenders.json`
1. 以政府電子採購網或醫院官方採購公告為來源。
2. 必須核對公告原文及附件；無法確認的欄位標示「未公告」或「待確認」。
3. 不得將搜尋摘要或未核實資料標記為已核實。
4. 更新案件時填入官方公告網址及資料更新日期。

## GitHub Pages
部署流程位於 `.github/workflows/pages.yml`。推送至 `main` 後會觸發部署。第一次使用時，請至 Repository → Settings → Pages，將 Build and deployment 的 Source 設為 **GitHub Actions**。

## 自動更新說明
目前設定的是網站自動部署，尚未設定自動爬取與核實政府／醫院採購公告。網站部署自動化不等於採購資料自動更新；採購資料需經來源查證後再更新 `data/tenders.json`。
